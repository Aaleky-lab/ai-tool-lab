# CEVYRA

AI tools tested, compared and explained in a static GitHub Pages site.

## Current system

- 20-tool searchable catalog with category and access filters
- Three-step AI Tool Finder
- Reusable dynamic tool overview page
- Five SEO-focused buyer guides
- Affiliate disclosure and internal affiliate-program audit
- `robots.txt`, XML sitemap, canonical URLs and social metadata
- Event measurement layer for tool opens, outbound clicks and finder results

## Measurement setup

`analytics.js` is ready for GA4 but intentionally ships with an empty `GA4_ID`, so no third-party tracking runs before a property is created. After creating the property, paste its measurement ID into that constant. Events are already named and wired:

- `tool_open`
- `outbound_click`
- `finder_result`

## Content package

`YOUTUBE-VIDEO-01.md` contains the first long-form YouTube script package and three Shorts. `AFFILIATE-AUDIT.md` contains the 20-tool affiliate action plan.
